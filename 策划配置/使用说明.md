# 战斗数值调整

今后统一编辑同目录 **战斗数值.xlsx**。单字、词组、规则、状态、遗物和怪物都在这份表中。

1. 按对象筛选要调整的字、词或机制，只修改原数值页的黄色格。灰色ID、默认值、范围和说明不可修改，不自行增删数值表、行或列。新增的机制查询页为只读参考，不参与导入。
2. 保存 Excel；可先双击“校验全部战斗数值.command”（Windows用 .bat）。
3. 双击“导入全部战斗数值.command”，看到“导入成功”后，关闭并重新启动游戏。
4. 需要撤销最近一次导入时，双击“恢复上次战斗数值”。它恢复游戏配置，不会回写 Excel；再次导入前请同步调整 Excel。

所有导入先完整检查，再原子替换一个 JSON 文件；无效数值、公式、缺行、重复ID或说明列被改动时，游戏配置不变。小数倍率允许小数，伤害、次数等要求整数，具体范围见行内。

Mac需要Python 3；脚本会自动寻找系统、Homebrew或本机已有运行环境。Windows需要Python 3（支持py -3或python）。无需Office组件和额外Python库。

## 表格内容

- 单字数值、词组数值：效果的基础值和超过2字的每字加成；具体含义参考处理器与默认机制说明。
- 效果参数：多段攻击的段数、每点资源倍率、百分比、费用与附加资源等。
- 战斗规则：玩家生命、开场/回合补字、热容、铜钱、盘面与战斗开场印章调整。
- 状态参数：状态衰减、易伤倍率、力量加成、减伤与持续回合。
- 遗物参数、战斗机制：原先写在代码中的收益、门槛、持续时间、复制层、镀金等。
- 起始字袋：新开局使用的实体字数量。
- 怪物、行动、机制参数、污染：沿用已有配置；怪物列明确当前层数、Boss/精英/小怪和投放区域。

字形、词配方、坐标、方向、数组索引、动画和UI尺寸属于结构，不是战斗平衡数值；不开放这些字段以免改变程序结构。游戏载入修改后，字词说明显示当前参数；重复旧默认值可能有歧义时，会明确标注以“当前配置”为准。

旧的怪物导入与恢复快捷脚本已转到本总表；旧“怪物数值.xlsx”保留为历史参考，不再作为当前游戏的导入来源。

开发/自动化：python3 tools/balance/import_battle_excel.py --check；导入不加--check；恢复加--restore。


## 成就配置

成就表为 `成就配置.xlsx`，含48项玉符成就、32个已接入指标和玉雕美术要求。改目标、名称、说明、前置、开关后保存，双击「导入成就配置」并重启游戏。另有「校验成就配置」与「恢复上次成就配置」；Mac用 `.command`，Windows用 `.bat`。

主界面「成就总览」显示所有启用项的解锁状态、条件和进度；达成时提示，结果跨局保存。默认沿用已确认v6玉符图案，名称为繁体；独立图标可在「徽章美术」填写。生成的 `data/achievements/catalog.json` 不影响战斗数值或玩家存档。详细约定见 `tools/achievements/README.md`。

## 机制查询

`战斗数值.xlsx` 从「机制导航」开始新增10张只读查询页，共710条记录。可以用表头筛选或 Excel 搜索，查看系统规则、65个单字、162个词组、29个怪物、25件遗物、状态与污染、全部注册事件分支、灯谜题库、版面词、旧远征印章及成就定义和统计口径。每条记录列出条件、效果、边界与实现依据。

机制页已保护以避免误改，保留查看和筛选。机制结构需要改代码；在这些页改文字不会改变游戏规则。原有12张数值表的620行数据和导入坐标保持不变，只读页不会写进游戏配置。

说明为2026-10-20当前本地工程与已加载配置的快照，并非实时同步。导入新的数值或修改机制代码后，需要重新生成查询内容。新冒险、经典节点模式、旧版远征和未接入功能分别标注，不能混用。特别是休整「镌刻／修饰」：新冒险实际给一枚实体镀金，经典节点模式才执行单字基础值加2；当前界面旧文案差异已记录在「系统机制只读」。

### 按单字查组词

另新增「组词速查」页：覆盖65个字、162个词，共335条字词搭配关系。筛选第一列「单字」，即可看到需要的其他字、组成的词、词效和配方顺序。10个暂无注册配方的字单独列明；「心连心」明确需要两枚「心」。

蓝色文字是工作簿内部超链接：原「单字数值」页可直接点击字形；「单字机制只读」页最右侧可点「查看N个词」；速查页可跳到完整词效或返回单字；完整词效页也可返回搭配列表。链接不依赖网络。若已筛选其他字，跳转后需清除原筛选以查看目标行。

机制查询区现共11页；「组词速查」同样只读，不参与数值导入，后续配方变化时需要同步刷新。
